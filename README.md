# dbg_alloc
**dbg_alloc** - catch memory bugs.

## Description
This small library that can trace memory bugs:
**Memory Leak**, **Heap corruption**, **Double Free**,
**Stack smashing**.

### Features
- **C89**/**ANSI C** code standard.
- **stb-style** library.

### Quick start
```c
#define DBG_ALLOC_SOURCE
/* Can wrap malloc() function */
#define WRAP_REAL_MALLOC
#include "dbg_alloc.h"

#include <stdlib.h>

int main(void) {
  int* test_data = NULL;
  
  /* Initialize allocator once: */
  InitAllocator(4096/*bytes*/);

  test_data = malloc(sizeof(int));

  /* Forget free! Running log. */
  AllocatorLog();

  /* Clear allocator: */
  KillAllocator();

  /* Program will be aborted. */
  return 0;
}
```

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
